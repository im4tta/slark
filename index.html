About

How Slark works

Slark (ស្លាក — Khmer for "tag") attaches invisible, checksum-verified provenance payloads to text and PNG images. This console is a faithful browser port of the pip install slark Python package — formats are byte-identical both ways.

Text format

CharCodepointMeaning
ZWSPU+200Bbit 0
ZWNJU+200Cbit 1
ZWJU+200Dstart/end sentinel

Frame: [2B length][4B CRC32][JSON], inserted after the first whitespace. The decoder scans every sentinel pair and only believes checksum-verified spans — emoji ZWJ sequences can't break it.

Image format ("SLK1")

BytesField
4magic "SLK1"
2payload length (BE)
4CRC32 of payload (BE)
≤256JSON payload

Written MSB-first into R/G/B LSBs, repeated in up to 512 evenly spaced chunks. Decode scans every copy, then falls back to bitwise majority voting across copies.

Signed marks

With a secret key, the payload gains sig — the first 8 bytes (hex) of HMAC-SHA256 over the canonical JSON of the other fields. Verification states:

  • signed — signature valid for your key
  • invalid — sig present but wrong (forged / tampered / wrong key)
  • unsigned — mark carries no signature
  • none — no mark at all

Honest limitations

  • Zero-width chars get stripped by many real-world pipelines (chat UIs, sanitizers).
  • Doesn't survive retyping, translation, OCR, or screenshots.
  • LSB image tags die on any lossy re-encode (JPEG/WebP/platform re-uploads).
  • Anyone who knows the technique can strip a tag; the HMAC only prevents forging one.
  • For adversarially robust AI-text watermarking you need statistical watermarks at generation time — a different, heavier approach.

CLI quick reference

pip install "slark[image]"

slark encode --text "Hello world" --model claude-sonnet-5 --key SECRET
slark decode --file out.txt --json          # --all for every mark
slark verify --file out.txt --key SECRET    # signed | invalid | unsigned | none
slark strip  --file out.txt                 # emoji-safe; --aggressive for all ZW
slark encode-image --file p.png --key SECRET --output out.png
slark decode-image --file out.png --json    # --no-vote to disable majority voting
slark verify-image --file out.png --key SECRET
slark strip-image  --file out.png --output clean.png
slark capacity --file p.png                 # copies / capacity report
